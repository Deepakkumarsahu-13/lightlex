A sleek, modern, and responsive personal portfolio website built to showcase software engineering projects, technical skill sets, and professional experience.

## ✨ Features

- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.
- **Project Showcase:** Highlights major technical builds with direct source code and demo links.
- **Skills Matrix:** Categorized view of languages, frameworks, and tools.
- **Interactive UI:** Smooth scrolling, clean typography, and minimalist UI components.
- **Contact Integration:** Easy-to-reach links for professional networking.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons & Assets:** FontAwesome / DevIcons
- **Version Control:** Git & GitHub
